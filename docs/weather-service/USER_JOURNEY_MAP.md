# 사용자 여정 지도

| 단계 | 사용자 목표·행동 | 접점 | 사용자의 질문 | 서비스가 해야 할 일 |
|---|---|---|---|---|
| 인지 | 날씨를 확인하려고 앱을 연다 | 앱 아이콘, 웹 첫 화면 | “무엇을 할 수 있지?” | 입력창과 질문 예시를 즉시 보여준다 |
| 시작 | 위치 권한을 검토한다 | 권한 안내 화면 | “왜 위치가 필요한가?” | 위치 사용 목적과 대안을 설명한다 |
| 질문 | “오늘 날씨 알려줘”를 입력/말한다 | 텍스트 입력, 음성 버튼 | “내 위치를 알아듣나?” | 질문을 확인하고 처리 상태를 보여준다 |
| 응답 | 날씨를 빠르게 확인한다 | 날씨 카드, 지도 | “지금 나갈 수 있나?” | 현재 날씨와 기준 시각을 명확히 표시한다 |
| 판단 | 옷·우산을 결정한다 | 생활 안내, 시간대별 예보 | “무엇을 준비하지?” | 행동 중심의 짧은 추천을 제공한다 |
| 재방문 | 다음 외출에도 사용한다 | 최근 위치, 알림 | “다시 물어봐도 빠를까?” | 최근 사용 흐름을 단순화한다 |

## 핵심 순간

첫 권한 요청과 첫 응답이 이탈을 결정한다. 권한 요청 전에는 위치가 필요한 이유를 한 문장으로 설명하고, 응답 화면에는 숫자보다 “우산을 챙기세요”처럼 결론을 먼저 보여준다.
