# 감정 그래프

감정 점수는 `-2(매우 부정적)`부터 `+2(매우 긍정적)`까지의 초기 가설이다. 실제 사용자 테스트 후 수정한다.

| 여정 단계 | 예상 감정 | 점수 | 감정 저하 원인 | 개선 장치 |
|---|---|---:|---|---|
| 앱 실행 | 호기심 | +1 | 기능을 바로 이해하지 못함 | 질문 예시를 첫 화면에 배치 |
| 위치 권한 | 경계심 | 0 | 개인정보가 걱정됨 | 이유·대안·설정을 명확히 안내 |
| 질문 입력 | 기대 | +1 | 음성/텍스트 인식 불확실 | 처리 중 상태와 재입력 제공 |
| 응답 대기 | 불안 | 0 | 네트워크 지연 | 진행 상태와 재시도 버튼 |
| 결과 확인 | 안도 | +2 | 필요한 정보가 한눈에 보임 | 결론 우선 카드 설계 |
| 외출 결정 | 확신 | +2 | 행동을 결정할 수 있음 | 우산·외투·미세먼지 추천 |

## 목표 곡선

`호기심 +1 → 경계심 0 → 기대 +1 → 안도 +2 → 확신 +2`

핵심은 권한 단계에서 감정이 크게 떨어지지 않도록 신뢰를 확보하고, 결과 화면에서 즉시 행동 가능한 답을 주는 것이다.
