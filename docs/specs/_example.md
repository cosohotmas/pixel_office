# 기능 Spec 작성 형식

## Why

- 누구의 어떤 문제를 해결하는가?
- 어떤 상황에서 필요한가?
- 무엇으로 성공 여부를 확인하는가?

## Goal

- 달성할 결과를 측정 가능한 문장으로 쓴다.
- 이번 작업에 포함하지 않을 범위를 `Out of Scope`에 쓴다.

## What

- Happy Path
- Edge Case
- 사용자에게 보이는 결과

## How

- 데이터 출처
- API와 저장 구조
- 권한과 보안
- 오류 처리

## AC

`Given → When → Then` 형식으로 테스트 가능한 조건을 쓴다.
