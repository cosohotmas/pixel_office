# Weather Foundation Spec

## Why

사용자는 현재 위치나 선택한 지역의 날씨를 확인하기 위해 여러 화면을 찾아야 합니다. 이 기능은 기상청 공개 데이터를 기준으로 오늘 날씨를 사실 그대로 보여주는 서비스의 기반입니다.

## Goal

- 위치가 확인되면 현재 지역의 날씨와 오늘 시간대별 예보를 보여준다.
- 위치를 거부해도 전국 날씨와 지역 검색을 제공한다.
- 모든 날씨 값에 출처와 발표·조회 시각을 표시한다.
- 사실 데이터와 서비스의 해석 문장을 구분한다.

### Out of Scope

- 근거 없는 개인별 행동지침
- 의료·재난 판단을 대신하는 문장
- 위치 이력의 장기 저장
- 음성 입력과 LangGraph 자동화

## What

### Happy Path

1. 사용자가 서비스를 연다.
2. 서비스가 위치 사용 목적을 설명한다.
3. 사용자가 위치를 허용한다.
4. 서비스가 기상청 데이터 기준 지역을 조회한다.
5. 현재 날씨와 오늘 시간대별 예보를 표시한다.
6. 출처, 발표 시각, 조회 시각을 표시한다.

### Location Denied

1. 사용자가 위치를 거부한다.
2. 서비스는 전국 날씨를 표시한다.
3. 사용자는 지역을 직접 검색할 수 있다.

### Edge Cases

| 상황 | 처리 |
|---|---|
| 위치를 확인할 수 없음 | 전국 보기와 지역 검색 제공 |
| 기상청 응답 지연 | 마지막 성공 시각과 재시도 표시 |
| 지역 변환 실패 | 원본 좌표를 표시하지 않고 오류 안내 |
| 출처·라이선스 확인 불가 | 해당 정보를 사실처럼 표시하지 않음 |

## How

### Data

- 1차 출처: 기상청 날씨누리·기상자료개방포털
- 저장하는 메타데이터: 지역, 발표 시각, 조회 시각, 출처 URL, 검증 상태
- 위치 데이터는 조회에 필요한 순간에만 사용한다.

### Display Layers

1. 사실: 기온·강수확률·강수량·바람·하늘 상태
2. 변환: 현재 위치에 맞춘 지역명과 시간대 표시
3. 해석: 사실과 구분되는 짧은 요약

### Security

- 위치 권한은 선택 사항이다.
- 위치 권한 거부 시에도 기능을 제공한다.
- API 키와 비밀값은 클라이언트에 노출하지 않는다.
- 사용자 위치 이력을 기본 저장하지 않는다.

## AC

### AC-01 — 위치 허용

- Given: 사용자가 위치 권한을 허용한다.
- When: 날씨 화면을 연다.
- Then: 현재 지역의 날씨, 오늘 예보, 출처와 발표 시각이 표시된다.

### AC-02 — 위치 거부

- Given: 사용자가 위치 권한을 거부한다.
- When: 날씨 화면을 연다.
- Then: 전국 날씨와 지역 검색이 표시되고 서비스가 중단되지 않는다.

### AC-03 — 출처 표시

- Given: 날씨 데이터가 정상적으로 조회된다.
- When: 날씨 카드가 표시된다.
- Then: 기관명, 데이터명, 원문 URL, 발표·조회 시각이 함께 표시된다.

### AC-04 — 데이터 오류

- Given: 기상청 데이터 조회가 실패한다.
- When: 날씨 화면을 연다.
- Then: 오류 상태, 마지막 성공 시각 또는 재시도 방법이 표시되고 출처가 없는 값을 새로 만들지 않는다.
