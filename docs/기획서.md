# 오늘 날씨 알려줘 — 서비스 기획서

## 1. 문제 상황

사용자는 날씨를 확인하려고 여러 앱을 열거나 현재 위치를 직접 검색해야 합니다. 단순히 오늘 날씨를 알고 싶은 상황에도 화면 이동과 정보 비교가 필요합니다.

## 2. 서비스 아이디어

앱 또는 웹앱을 열고 “오늘 날씨 알려줘”라고 입력하거나 말하면, 사용자의 현재 위치를 확인해 날씨와 외출에 필요한 정보를 보여주는 대화형 날씨 서비스입니다.

## 3. 핵심 기능

- 현재 위치 자동 확인
- 기상청 날씨 데이터 연동
- 현재 위치 지도 표시
- 오늘 날씨와 시간대별 예보 제공
- 음성 또는 텍스트 질문
- 우산·외투 등 생활 안내
- 미세먼지·강수확률·체감온도 제공

## 4. 사용자 경험

`앱 실행 → 위치 권한 허용 → “오늘 날씨 알려줘” 입력 → 현재 위치 지도와 날씨 표시 → 외출 준비 결정`

### 대표 사용자 흐름

1. 사용자가 서비스를 실행한다.
2. 서비스가 위치 사용 목적을 설명하고 권한을 요청한다.
3. 사용자가 위치 권한을 허용한다.
4. 사용자가 텍스트 또는 음성으로 날씨를 질문한다.
5. 서비스가 현재 위치의 날씨, 예보, 생활 안내를 보여준다.
6. 사용자가 우산·외투 등 외출 준비를 결정한다.

## 5. 차별점

복잡한 메뉴를 탐색하지 않고 자연어로 질문하면 바로 답해주는 대화형 경험입니다. 숫자만 나열하지 않고 “우산을 챙기세요”, “얇은 외투가 좋아요”처럼 행동으로 이어지는 안내를 제공합니다.

## 6. MVP 범위

### 포함

- 위치 권한과 현재 위치 확인
- 현재 날씨 및 오늘 시간대별 예보
- 지도와 행정구역명 표시
- 텍스트 질문
- 기본 생활 안내

### 후속 개발

- 음성 입력
- 즐겨찾는 장소
- 날씨 알림
- 미세먼지 상세 분석

## 7. 성공 기준

사용자가 위치 권한을 허용한 뒤 “오늘 날씨 알려줘”를 입력하면 10초 이내에 현재 위치의 날씨, 시간대별 예보, 지도, 생활 안내를 확인할 수 있어야 합니다.

## 8. 다음 결정 사항

- 음성 기능을 MVP에 포함할지 여부

## 9. 정보 출처와 라이선스

외부 정보는 공식 원문을 우선 사용하고, 기관명·데이터명·원문 URL·발표 또는 조회 시각을 표시한다. 기상청 자료는 공공누리 표시 유형과 개별 이용 조건을 확인한 뒤 사용한다. 지도·접근성 데이터는 데이터셋별 이용약관과 라이선스를 확인한다.

상세 기준은 [`docs/SOURCES_AND_LICENSES.md`](./SOURCES_AND_LICENSES.md)에 기록한다.
